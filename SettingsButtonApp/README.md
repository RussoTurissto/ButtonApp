# SettingsButtonApp

Простое Android-приложение на Kotlin с одной кнопкой «Настройки».

- Короткое нажатие: «Вы успешно нажали», затем приложение закрывается примерно через 2 секунды.
- Долгое нажатие: «Вы успешно задали кнопку», затем приложение закрывается примерно через 2 секунды.

APK будет доступен в артефактах успешного запуска GitHub Actions с именем `button-app-debug-apk`.
